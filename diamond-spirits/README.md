# DIAMOND SPIRITS

キャッチャー後方視点で一球ずつ勝負する、リアル志向のプロ野球ゲーム。打撃はミートカーソルとタイミング、投球は球種・コース・リリースゲージで決まり、打球は物理計算で飛び、守備と走塁は自動で進む。外部ライブラリ・外部アセット不要。

## 遊び方

`index.html` をブラウザで開くだけで起動します。

1. メニューで **自チーム / 相手チーム**（架空の4球団）、**先攻・後攻**、**イニング数（3 / 6 / 9回）**、**難易度** を選ぶ
2. **PLAY BALL**。攻撃中は打撃、守備中は投球を自分で操作する
3. 9回（または設定したイニング）終了時点で勝敗が決まる。同点なら延長戦。後攻がリードした時点でサヨナラ

### 打撃

| 操作 | マウス | キーボード | スマホ |
|---|---|---|---|
| ミートカーソル移動 | マウス移動 | 矢印 / WASD | 画面をドラッグ |
| スイング | 左クリック | スペース / Enter / J | SWING ボタン |
| 強振 | 右クリックで切替 | E で切替 / Shift・K 押しっぱなし | 強振 ボタン |

- ボールが**カーソルの中に入った状態で、ちょうどいいタイミングで振る**と打てる
- カーソルの**中心で捉えるほど強い打球**。ボールがカーソル中心より**上ならフライ**、**下ならゴロ**になる
- **早めに振ると引っ張り**、**遅れると流し打ち**。大きくずれるとファウル
- **強振**はカーソルが小さくなりタイミングもシビアになるが、打球速度が上がる
- カーソルの大きさは打者の**ミート**、打球の強さは**パワー**で決まる。走力は走塁に効く

### 投球

| 操作 | マウス | キーボード | スマホ |
|---|---|---|---|
| 球種選択 | 下の球種ボタン | 1〜4 | 球種ボタン |
| コース指定 | マウス移動 | 矢印 / WASD | 画面をドラッグ |
| 投球開始 / リリース | クリック（2回） | スペース（2回） | 投球 ボタン（2回） |
| 継投 | 継投ボタン | P | 継投ボタン |

- 1回目の入力で投球動作が始まり、コースの周りに**縮んでいく白い円**が現れる
- 白い円が**黄色い円に重なった瞬間**にもう一度押すと「ベスト」。制球が良くなり球速も少し上がる
- 投手の**コントロール**が低いほど、また**スタミナ**が減るほど狙ったコースから外れやすく、球速も落ちる
- 点線の矢印はその球種の変化の向き。球種の■の数は変化量（ストレートは伸び）

守備と走塁はオートです。プレー中はクリック（または右上のボタン）で早送りできます。

## しくみ

- **投球**：リリースから捕手までの軌道を、重力と「伸び（ホップ成分）」の2次項、変化球の終盤で効く3次項で計算。球速は投手の最速×球種係数で、疲労やリリースの出来で上下する
- **打撃判定**：スイング開始から0.14秒後にバットがボールに届く。そのときのズレ（時間）と、カーソルとボールの位置の差から、打球速度・打球角度・方向を決める
- **打球**：空気抵抗つきの弾道計算。地面でのバウンド・転がり、フェンスでの跳ね返り、フェンス越えのホームラン、ワンバウンドで越えるエンタイトルツーベースまで扱う。フェア / ファウルは落下点や一・三塁ベース通過時の位置で判定
- **守備**：9人の野手それぞれが、反応時間と加速を含めて打球の軌道上のどこで追いつけるかを計算し、最初に届く野手が捕球に向かう。ノーバウンドで捕ればアウト。捕球後は「アウトにできる走者」を探して送球し、間に合えばアウト（ダブルプレーも発生）
- **走塁**：走者はボールの到達予測時間と自分の足を比べて、進塁・次の塁を狙う・自重を判断する。フライは帰塁して待ち、捕球されたらタッチアップ、落ちたらスタート。三つ目のアウトがフォースアウトなら得点は無効
- **CPU**：CPU投手はカウントに応じて球種とコースを配球し、疲れたら継投、リードした最終回は抑えを投入。CPU打者は球の見極め（選球眼）、ストレート待ちで緩い球にタイミングを崩されるなど、能力に応じたスイングをする

## 難易度

| | かんたん | ふつう | プロ |
|---|---|---|---|
| 投球の見え方 | ゆっくり（×1.5） | やや遅い（×1.22） | 実速 |
| カーソル / タイミング幅 | 大 | 中 | 標準 |
| 投球の到達点マーカー | あり | なし | なし |
| CPU打者 | 弱め | 標準 | 強め |

## 球団（すべて架空）

- **帝都アルバトロス**（ALB）— 4番 岩鬼の長打力と剛腕エース 神崎
- **浪速ライトニング**（LTN）— 俊足の1番 赤星と技巧派左腕 真田
- **北都スノーウルフ**（WLV）— 巧打者揃いの打線と制球力Aの冬木
- **博多オルカズ**（ORC）— パワー98の鯨岡を擁する重量打線と156km右腕 荒波

## ファイル構成

- `engine.js` — ルール・投球と打球の物理・守備と走塁・CPU思考（DOM非依存。Node からも読み込めるので対戦シミュレーションで調整できる）
- `game.js` — 3D描画（自前の透視投影）、入力、演出、画面遷移
- `index.html` / `style.css` — メニューとUI

## ローカルで動かす

```bash
cd diamond-spirits
python3 -m http.server 8080
# ブラウザで http://localhost:8080 を開く
```
