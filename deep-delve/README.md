# DEEP DELVE（深層採掘）

ランタンの灯りだけを頼りに洞窟を奥へ奥へと潜り、鉱石を掘り集める一人称3D探索シミュレーション。外部ライブラリ・外部アセット不要——レイキャスティングによる3D描画、洞窟生成、テクスチャ、効果音まですべて自前で実装。

## 遊び方

`index.html` をブラウザで開くだけで起動します。

- **W / S** — 前進・後退　**A / D** — 横移動
- **← → / マウス** — 視点回転（画面クリックでマウス操作をロック）
- **E / SPACE / 左クリック長押し** — 採掘
- **M** — 地図の拡大表示
- **C / Tab** — 携帯工房（クラフト）を開く。開いている間は時間が止まる。数字キー 1〜9 でも製作可

## ルール

- 壁に埋まった鉱石を掘って集める。深い層ほど貴重な鉱石が出やすい
  - 銅 ¥5 → 鉄 ¥10 → 金 ¥25 → 水晶 ¥60 → ルビー ¥120
- スコアは**総資産**（手持ちの鉱石＋工芸品の価値の合計）
- ただの岩も掘れる。行き止まりを掘り抜いて近道を作ったり、岩の内側に隠れた鉱脈を探すこともできる
- 青白く光る**縦穴**に入ると次の層へ降りる（燃料が少し回復する）
- ランタンの燃料は時間とともに減り、照らせる範囲も狭まっていく。落ちている**油瓶**で補給できる
- 燃料が尽きたら終了。到達した深さと稼いだ金額が記録される（自己ベストはブラウザに保存）
- 水晶・ルビー・金は暗闇でもわずかに光るので、遠くからでも見つけられる

## クラフト

鉱石は工房で加工できる。何を作るかで「資産を増やす」か「探索力を上げる」かの選択になる。

| 分類 | 品目 | 素材 | 効果 |
|---|---|---|---|
| 工芸品 | 銅線 | 銅×3 | ¥22（付加価値 +¥7） |
| 工芸品 | 鉄インゴット | 鉄×3 | ¥42（+¥12） |
| 工芸品 | 金の指輪 | 金×2・銅×1 | ¥75（+¥20） |
| 工芸品 | 水晶レンズ | 水晶×2 | ¥160（+¥40） |
| 工芸品 | ルビーの首飾り | ルビー×1・金×2・水晶×1 | ¥340（+¥110） |
| 工芸品 | 宝冠 | 金×4・ルビー×2・水晶×2 | ¥900（+¥440） |
| 道具 | 鉄のツルハシ | 鉄×3・銅×2 | 採掘速度 ×1.6 |
| 道具 | 水晶のツルハシ | 水晶×2・鉄×3（鉄のツルハシが必要） | 採掘速度 ×2.4 |
| 道具 | 反射板付きランタン | 銅×2・水晶×1 | 照らせる範囲 +30% |
| 消耗品 | 携帯燃料 | 銅×2・鉄×1 | 燃料 +30 |
| 消耗品 | 探鉱コンパス | 金×1・鉄×2 | その層の縦穴の位置を地図に表示 |

工芸品は材料より高い価値を持つので、作るほど資産が増える。道具と消耗品は素材の価値を失う代わりに、より深く・より多く掘るための力になる。

## 特徴

- 層ごとにセルオートマトンで洞窟を自動生成。縦穴は開始地点から最も遠い場所に置かれる
- 燃料残量に連動するランタンの照明半径とゆらぎ、残量わずかでの心音・明滅演出
- 見た場所だけが記録されていく探索マップ
- 手続き生成の岩・鉱石テクスチャ、洞窟の水滴音などの環境音

## ローカルで動かす

```bash
cd deep-delve
python3 -m http.server 8080
# ブラウザで http://localhost:8080 を開く
```
