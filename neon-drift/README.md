# NEON DRIFT

シンセウェイブ風のネオンビジュアルで彩られた、ブラウザで動くツインスティック・シューティングゲーム。外部アセット不要（サウンドも Web Audio API でリアルタイム生成）。

## 遊び方

`index.html` をブラウザで開くだけで起動します。

- **WASD / 矢印キー** — 移動
- **マウス** — 照準（自機は常にマウス方向を向く）
- **左クリック（長押し可）** — 発射
- **SHIFT または右クリック** — ダッシュ（短時間の無敵＋高速移動、クールダウンあり）

## 特徴

- レトロなシンセウェイブ風の背景（パースグリッド、グラデーションサン、瞬く星）
- ネオングロー表現（`shadowBlur` を使った Canvas 描画）とヒット時のスクリーンシェイク
- 4種類の敵（追尾型・射撃型・ジグザグ型・タンク型）とウェーブが進むごとに増す難易度
- コンボ・スコア倍率システム
- ライフ回復／連射強化のパワーアップドロップ
- Web Audio API によるプロシージャル効果音（外部音源ファイル不要）

## ローカルで動かす

```bash
cd neon-drift
python3 -m http.server 8080
# ブラウザで http://localhost:8080 を開く
```

（`index.html` を直接ダブルクリックで開いても動作します）
