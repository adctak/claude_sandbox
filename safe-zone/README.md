# SAFE ZONE

超弾幕の中に、ただ一つだけ弾が通らない場所がある——巨大ボス「終焉機神 OMEGA」の弾幕を、一瞬だけ見えた赤い円の記憶を頼りにかわす弾幕シューティング。外部ライブラリ・外部アセット不要。

## 遊び方

`index.html` をブラウザで開くだけで起動します。

- **矢印 / WASD** — 移動
- **SHIFT** — 低速移動（当たり判定を表示）

1. 画面のどこかに**赤い円**が現れ、ボスの目に3秒のカウントダウンが刻まれる
2. **円が見えるのは最初の1秒だけ**。弾幕開始の2秒前に消え、弾幕が終わるまで再表示されない——位置を覚えて飛び込め
3. 3秒後、ボスが画面を埋め尽くす超弾幕を放つ。**弾の軌道は赤い円の中を絶対に通らない**ので、円の中にいれば生き残れる
4. 弾幕が止むと円が再び現れ、残った弾は得点に変わり、円は別の場所へ移動する
5. また3秒後に次の弾幕——これを繰り返す

ラウンドが進むほど円は小さく、弾幕は濃く速くなる。ライフは3つ。弾の近くをすり抜けると GRAZE（かすり）で得点が入る。

## ラスボス：終焉機神 OMEGA

画面上部に陣取る巨大な機神。5枚刃の翼、垂れ下がる触手、左右の砲台ポッド、そしてプレイヤーを追い続ける巨大な単眼を持つ。弾幕はすべてこのボスの目と砲台から放たれる。

- 自機は**自動でツインレーザーを連射**する。ボスの真下にいるほどダメージを与えられる
- **HP 2/3 で PHASE 2**：左右の砲台が起動し、弾幕の発射源が3つに増える
- **HP 1/3 で PHASE 3（暴走）**：機体が赤熱して亀裂が走り、弾幕パターンが1つ増え密度も上がる
- HPを削り切ると大爆発とともに撃破——**VICTORY**。残りライフに応じてボーナス

安全地帯の位置を覚えながら、できるだけボスの真下の円を狙う——守りと攻めの両立が鍵。

## 安全地帯の保証の仕組み

弾は発射の瞬間に、その弾の**軌道全体を先に計算**してから撃たれる。軌道が一度でも「円の半径＋弾の半径＋自機の当たり判定」の内側に入る弾は、最初から発射されない。

弾の動きはすべて時間の関数として厳密に定義されていて（直進・加速・一定速度で旋回する曲線弾）、発射前の検査と実際の移動がまったく同じ式で計算されるため、曲がる弾や加速する弾を含めて円の中へは一発も入らない。

## 弾幕パターン

- **リング** — 発射源から全方位へ広がる輪
- **スパイラル** — ボスの目から回転しながら撃ち出される4本腕の渦
- **レイン** — 画面上端から降り注ぐ弾の雨
- **フラワー** — 左右交互に曲がる弾で描く花模様
- **ケージ** — 安全地帯の縁をかすめるように撃ち込まれ、円の周りに弾の壁を作る
- **スイープ** — 左右の砲台が首を振りながら撃ち下ろす弾流
- **バースト** — ボスの機体から放たれ、空中で止まったように浮かび、急加速して飛び散る砲弾

## ローカルで動かす

```bash
cd safe-zone
python3 -m http.server 8080
# ブラウザで http://localhost:8080 を開く
```
