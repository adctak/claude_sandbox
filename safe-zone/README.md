# SAFE ZONE

超弾幕の中に、ただ一つだけ弾が通らない場所がある——赤い円を目指して逃げ込む弾幕シューティング。外部ライブラリ・外部アセット不要。

## 遊び方

`index.html` をブラウザで開くだけで起動します。

- **矢印 / WASD** — 移動
- **SHIFT** — 低速移動（当たり判定を表示）

1. 画面のどこかに**赤い円**が現れ、3秒のカウントダウンが始まる
2. 3秒後、画面を埋め尽くす超弾幕が始まる。**弾の軌道は赤い円の中を絶対に通らない**ので、円の中にいれば生き残れる
3. 弾幕が止むと、残った弾は得点に変わり、赤い円は別の場所へ移動する
4. また3秒後に次の弾幕——これを繰り返す

ラウンドが進むほど円は小さく、弾幕は濃く速くなる。ライフは3つ。弾の近くをすり抜けると GRAZE（かすり）で得点が入るので、円の縁ぎりぎりを攻めるほど稼げる。

## 安全地帯の保証の仕組み

弾は発射の瞬間に、その弾の**軌道全体を先に計算**してから撃たれる。軌道が一度でも「円の半径＋弾の半径＋自機の当たり判定」の内側に入る弾は、最初から発射されない。

弾の動きはすべて時間の関数として厳密に定義されていて（直進・加速・一定速度で旋回する曲線弾）、発射前の検査と実際の移動がまったく同じ式で計算されるため、曲がる弾や加速する弾を含めて円の中へは一発も入らない。

## 弾幕パターン

- **リング** — 発射源から全方位へ広がる輪
- **スパイラル** — 回転しながら撃ち出される4本腕の渦
- **レイン** — 画面上端から降り注ぐ弾の雨
- **フラワー** — 左右交互に曲がる弾で描く花模様
- **ケージ** — 安全地帯の縁をかすめるように撃ち込まれ、円の周りに弾の壁を作る
- **スイープ** — 左右の端から首を振りながら撃つ弾流
- **バースト** — 空中で止まったように浮かび、急加速して飛び散る砲弾

## ローカルで動かす

```bash
cd safe-zone
python3 -m http.server 8080
# ブラウザで http://localhost:8080 を開く
```
