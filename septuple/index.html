7セプタプル

並んだコマの合計が7の倍数になったら、そこまで自分の色に返す数字リバーシ。

0白

0黒

ルール

  1. コマは1〜6が8枚ずつと7が1枚、計49枚。1〜6を4枚ずつ、お互いに配ります。
  2. 先攻（黒）が7のコマを黒で盤の中央に置いて始めます。
  3. 手番ではコマを1枚選んで空きマスに置き、8方向それぞれで合計が7の倍数になるところまで自分の色に返します。
  4. パスはありません。すべてのコマを置いたら終了で、自分の色が多いほうの勝ちです。
  1. 49枚のコマをよくシャッフルして山コマにします。
  2. 先攻（黒）が山コマの最初の1枚を白で中央に置いて始めます。
  3. 手番では山コマから1枚引き、空きマスに置いて返します。どの数字が来るかは運次第です。
  4. パスはありません。山コマがなくなったら終了で、自分の色が多いほうの勝ちです。

ルールブックのトラップ（☣）ルールは、トラップ発動カードの内容が未定義のため、この版には入っていません。

配置順位

置くコマで返せるマスが1つでもあるなら、そのどれかに置かなければいけません。返せるマスがないときだけ、好きな空きマスに置けます。置けるマスには金色の印が付きます。

返し方の例（左端に置いた場合）

2345→2345

2+3+4+5 = 14。7の倍数なのですべて白になります。

52345→52345

4までで14。最後の5は足すと19なのでそのままです。

2345→2345

自分のコマも合計に含めます。

置いたコマをまたいで足すことや、間が空いたコマを足すことはできません。7の倍数になる地点が複数ある場合は、いちばん遠い地点まで返します。

キーボード: 1〜6 で数字を選択、矢印キーでマス移動、Enter で置く、U で1手戻す、H でヒント。

棋譜

まだコマは置かれていません。
