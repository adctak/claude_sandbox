# セプタプル

並んだコマの合計が7の倍数になったら、そこまで自分の色に返す数字リバーシ。7×7の盤で遊ぶ2人対戦（CPU対戦も可）。

## 遊び方

`index.html` をブラウザで開くだけで起動します。

### クラシック

1. コマは1〜6が8枚ずつと7が1枚、計49枚。1〜6を4枚ずつ、お互いに配る
2. 先攻（黒）が7のコマを黒で盤の中央に置いて始める
3. 手番ではコマを1枚選んで空きマスに置き、8方向それぞれで合計が7の倍数になるところまで自分の色に返す
4. パスはなし。すべてのコマを置いたら終了で、自分の色が多いほうの勝ち

### 山コマ（ver2）

49枚をシャッフルした山から1枚ずつ引いて置く。どの数字が来るかは運次第。

### 配置順位

置くコマで返せるマスが1つでもあるなら、そのどれかに置かなければならない。返せるマスがないときだけ、好きな空きマスに置ける。

## 操作

- **1〜6** — 数字を選択（クラシック）
- **矢印キー** — マス移動、**Enter** — 置く
- **U** — 1手戻す、**H** — 返せる枚数のヒント、**R** — 最初から

## マニュアル

子ども向けの絵つきマニュアルは [`manual.html`](manual.html) にあります。ゲーム画面の「📖 マニュアル」から開けます。たしざんで コマが ひっくりかえる ようすを、アニメーションで見られます。
