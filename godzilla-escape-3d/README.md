# KAIJU RUN

怪獣に街を破壊され尽くす中、逃げ惑う一人の視点で駆け抜ける一人称3Dパニックゲーム。攻撃は前後左右、あらゆる方向から来る——自由に動き回って全方位から逃げ惑え。外部ライブラリ・外部アセット不要——3D投影も音もすべて自前で実装（Canvas 2D による自作3Dレンダリングと Web Audio API によるリアルタイム効果音）。

## 遊び方

`index.html` をブラウザで開くだけで起動します。

- **W / S** — 前進・後退
- **A / D** — 左右へ平行移動（ストレイフ）
- **← →** — 視点を回転
- **↑ / SPACE** — ジャンプ
- **F / クリック** — パンチ

自由に動き回れる広場を、奥にある光る門（ゴール）目指して進む。

## 全方位の脅威

怪獣の一撃は、あなたの**前・後・左・右**のどこからでも予告なく来る（画面の対応する方向に警告が表示される）。標的にされるのは常に「今あなたがいる場所」なので、**その場に留まると必ず被弾する**——警告が出たら、その場から離れて距離を取れ。攻撃してくるのは常に実際に表示されているゴジラ本体そのものなので、警告の方向を見れば彼が向かってくる様子が見える。

- 前・左・右からの一撃：**移動して距離を取る**しかかわす方法はない
- 背後からの一撃：**移動**でも**ジャンプ**でもかわせる
- 全方位の衝撃波：**移動**でも**ジャンプ**でもかわせる

## 挑発

正面近くのゴジラに**パンチ**を当てると挑発成功——だが怒ったゴジラは即座に正面から反撃してくる。ハイリスク・ハイリターンな一手として、逃走の合間に一発かましてやれ。

足元には瓦礫・炎・車の残骸も点在しており、触れると被弾する。3つのライフを守りながらゲートに辿り着ければ脱出成功。

## 特徴

- Three.js等の3Dライブラリを一切使わず、視点回転を含む透視投影・奥行きソートを Canvas 2D 上に自前実装
- レーン固定のランナーではなく、平面を自由に移動・旋回できる一人称視点
- ゴジラは常時徘徊しつつ、攻撃の瞬間には実際にその方向へ突進してくる——警告表示と本体の動きが完全に連動
- 攻撃方向を常に画面上に警告表示し、コンパスでゴール方向も提示——周囲把握と回避行動を両立させる設計
- パンチで挑発できる、逃げるだけでない攻めの選択肢
- 一人称視点のヘッドバウンス、被弾時のスクリーンシェイクと画面フラッシュで疾走感を演出
- 建物の炎上・崩落など、背景でも進行する破壊演出
- Web Audio API によるプロシージャル効果音（外部音源ファイル不要）

## ローカルで動かす

```bash
cd godzilla-escape-3d
python3 -m http.server 8080
# ブラウザで http://localhost:8080 を開く
```

（`index.html` を直接ダブルクリックで開いても動作します）
