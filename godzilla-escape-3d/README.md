# KAIJU RUN

怪獣に街を破壊され尽くす中、逃げ惑う一人の視点で駆け抜ける一人称3Dエンドレスランナー。外部ライブラリ・外部アセット不要——3D投影も音もすべて自前で実装（Canvas 2D による自作3Dレンダリングと Web Audio API によるリアルタイム効果音）。

## 遊び方

`index.html` をブラウザで開くだけで起動します。

- **← → / A D** — レーン移動（3車線）
- **↑ / W / SPACE** — ジャンプ

道路には瓦礫・炎・車の残骸が現れる。レーン移動でもジャンプでも回避可能。

怪獣は道路脇であなたと並走しながら、時折決定的な一撃を繰り出してくる：

- **尻尾払い**：画面を横切る一撃。**ジャンプ**でかわせ（レーン移動は無効）
- **踏みつけ**：特定レーンに巨大な足が落ちてくる。**レーン移動**でかわせ（ジャンプは無効）

3つのライフを守りながら、目標距離まで走り切れれば脱出成功。

## 特徴

- Three.js等の3Dライブラリを一切使わず、透視投影・奥行きソートを Canvas 2D 上に自前実装
- 一人称視点のヘッドバウンス、被弾時のスクリーンシェイクと画面フラッシュで疾走感を演出
- 怪獣の一撃ごとに異なる回避手段（ジャンプ／レーン移動）を要求する反射神経ゲーム性
- 建物の炎上・崩落など、背景でも進行する破壊演出
- Web Audio API によるプロシージャル効果音（外部音源ファイル不要）

## ローカルで動かす

```bash
cd godzilla-escape-3d
python3 -m http.server 8080
# ブラウザで http://localhost:8080 を開く
```

（`index.html` を直接ダブルクリックで開いても動作します）
