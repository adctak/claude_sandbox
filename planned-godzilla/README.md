# 計画的ゴジラ

タワーディフェンス——ただし敵は1体だけ。ゴジラは極めて計画的で、決まったルートを進み、決まった時刻に東京タワーを破壊し、都庁を踏みつけ、スカイツリーに登って街を焼き払う。プレイヤーはその「計画」を妨害するオペレーターとして、戦車・ミサイル・補強・消防車を駆使してスケジュールを狂わせる。外部アセット不要（サウンドも Web Audio API でリアルタイム生成）。

## 遊び方

`index.html` をブラウザで開くだけで起動します。

- **戦車 設置**（¥120）— ボタンを押して配置モードにし、ゴジラの進路上をクリックして設置。触れるとゴジラは足止めされ、時間を浪費する
- **ミサイル発射**（¥150）— ゴジラの現在地に着弾。移動フェーズでは足止め、登頂フェーズでは登頂ゲージを削る
- **都庁を強化**（¥150）— 都庁の耐久値を+1。踏みつけ攻撃を耐えきるには規定値まで貯める必要がある
- **消防車 出動**（¥130）— 展開すると、放火フェーズでの延焼速度を下げる

## ゴジラの「計画」

1. **東京タワー**：スケジュール通りの時刻に到達すると破壊される。**戦車で足止めして遅らせ、時間切れに追い込め**
2. **都庁**：到達すると必ず踏みつける。**あらかじめ強化しておけば倒壊を防げる**
3. **スカイツリー**：到達すると登り始める。**ミサイルを撃ち込み続けて登頂ゲージを削り切れば、登頂を阻止できる**
4. 登頂を許してしまった場合、街への放火が始まる。**消防車を出動させて延焼を食い止めろ**

3つの計画すべてを阻止できれば完全勝利。何もしなければ、ゴジラは寸分違わず計画を完遂する。

## 特徴

- 単体ボスを相手にした3段階＋保険1段の異なる防衛ミニゲーム構成
- 横スクロールするカメラと視差スクロールの東京の街並み
- 「本日の運行計画」パネルが鉄道の運行表のようにリアルタイムで成否を表示
- 予算管理・クールダウン管理を伴うリアルタイム戦略
- Web Audio API によるプロシージャル効果音（外部音源ファイル不要）

## ローカルで動かす

```bash
cd planned-godzilla
python3 -m http.server 8080
# ブラウザで http://localhost:8080 を開く
```

（`index.html` を直接ダブルクリックで開いても動作します）
