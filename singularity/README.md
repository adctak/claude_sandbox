# SINGULARITY

中心に固定されたブラックホールを操り、押し寄せる敵と爆弾を迎撃するアーケードディフェンスゲーム。外部アセット不要（サウンドも Web Audio API でリアルタイム生成）。

## 遊び方

`index.html` をブラウザで開くだけで起動します。

- **マウス** — 照準。ブラックホールは画面中央に固定されたまま動かない
- **左クリック / SPACE（長押し可）** — 照準方向へ球を発射する
- **↓キー** — 引力を強める（デフォルト） ／ **↑キー** — 斥力に切り替える

## ゲームループ

1. 敵は画面端から出現し、渦を巻きながらブラックホールに吸い込まれていく
2. **引力中**は、敵自体が吸い込まれても無害（むしろブラックホールの糧になりわずかに成長する）
3. しかし敵は吸い込まれる途中で**爆弾**を置いていく。爆弾も同じ重力で落ちていき、**引力中に吸い込まれると被弾する**
4. 球を爆弾に命中させれば、吸い込まれる前に安全に解体できる（高得点）。球は敵にも命中させられる（さらに高得点。倒せばそれ以上爆弾を置かれずに済む）
5. **↑キーで斥力に切り替えると、あたり判定が反転する**：敵はブラックホールに触れると即座に撃破され、爆弾は触れても無害化される（ただし敵は同時に吹き飛ばされ吸収による成長は得られない）
6. 敵は球を避けるように不規則に動き回るため、狙い撃つには先読みが必要
7. HPが尽きるとゲームオーバー。生存時間・撃破数・解体数でスコアを競う

## 特徴

- 「近づくほど吸い寄せるブラックホール」を、無害な捕食（敵）と危険な被弾（爆弾）の二重構造で表現
- ↑↓キーで引力・斥力を連続的に切り替え、あたり判定の意味そのものが反転する駆け引き
- 固定砲台としてのブラックホール、渦を巻いて落ちる・吹き飛ぶ敵と爆弾の物理演出。極性に応じて色調（ピンク=引力／シアン=斥力）が変化
- 敵の回避AI（球の軌道を検知して横に逃げる）による駆け引き
- コンボ・スコア倍率システム、被弾時のスクリーンシェイクと画面フラッシュ
- Web Audio API によるプロシージャル効果音（外部音源ファイル不要）

## ローカルで動かす

```bash
cd singularity
python3 -m http.server 8080
# ブラウザで http://localhost:8080 を開く
```

（`index.html` を直接ダブルクリックで開いても動作します）
