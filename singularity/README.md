# SINGULARITY

「穴を操って物を吸い込む」系ゲームのブラックホール版。近づくほど強く吸い寄せるが、獲物のほとんどは気づいて逃げてしまう。吸い込んだ獲物は吐き出して他の獲物にぶつけられ、命中すると麻痺する——その隙を突いて吸い込め。外部アセット不要（サウンドも Web Audio API でリアルタイム生成）。

## 遊び方

`index.html` をブラウザで開くだけで起動します。

- **マウス移動** — ブラックホールを操作する。重力の井戸なので少し遅れてついてくる
- **左クリック / SPACE** — 吸い込んで貯めた獲物をマウス方向へ吐き出す。命中した獲物は数秒間麻痺する
- 麻痺した獲物は抵抗しないので、近づけば一瞬で吸い込める
- 自分より小さい獲物しか吸い込めない。育つほど、吸引範囲・吸引力・飲み込めるサイズが大きくなる

## ゲームループ

1. 重力範囲（吸引半径）に入った獲物は逃げ始める。近いほど吸引力が強く、逃げる速度を上回ると引き寄せられる
2. だいたいは逃げ切られるので、獲物を貯めた弾（吐き出し攻撃）を当てて足止めする
3. 麻痺中の獲物に近づいて吸い込み、質量とスコアを稼ぐ
4. 育つほど大きな獲物（中型・大型）も解禁され、より高得点になる
5. 制限時間（90秒）でスコア・捕食数・最大質量が確定する

## 特徴

- 近接ほど強くなる重力吸引と、獲物の逃避行動が拮抗するシミュレーション的な駆け引き
- 吐き出し→命中→麻痺→捕食、というコンボ性のある捕食ループ
- 育つほど強い獲物が解禁されるダイナミックな難易度・報酬曲線
- 降着円盤・イベントホライズンのネオングロー表現、粒子が渦を巻いて吸い込まれる演出
- Web Audio API によるプロシージャル効果音（外部音源ファイル不要）

## ローカルで動かす

```bash
cd singularity
python3 -m http.server 8080
# ブラウザで http://localhost:8080 を開く
```

（`index.html` を直接ダブルクリックで開いても動作します）
